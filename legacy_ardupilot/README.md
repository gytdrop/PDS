# Legacy ArduPilot Stack Archives

This directory contains legacy components, scripts, and documentation from the original **ArduPilot SITL + Gazebo Harmonic + MAVProxy** simulation stack before the project was migrated to **PX4 Autopilot (v1.17) + Micro XRCE-DDS + ROS 2 (Humble)**.

## Contents
- **`sample_drone_flight.py`**: The original MAVLink/pymavlink Python flight script using guided mode, takeoff, square waypoint navigation, and RTL.
- **Obsidian Vault Archive**: Complete documentation of the ArduPilot installation and setup is preserved in the Obsidian vault under:
  [`Drone Club DC Vault/Simulation/Old Stack - ArduPilot/`](file:///home/gytdrop/Documents/PROJECTS/DC-%20Drone%20Club/Drone%20Club%20DC%20Vault/Simulation/Old%20Stack%20-%20ArduPilot/)

For the migration rationale, decommissioning ledger, and verification benchmarks, see [`PX4 ROS2 Migration Ledger.md`](file:///home/gytdrop/Documents/PROJECTS/DC-%20Drone%20Club/Drone%20Club%20DC%20Vault/Simulation/PX4%20ROS2%20Migration%20Ledger.md).
